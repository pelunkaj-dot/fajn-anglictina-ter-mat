# Fajn angličtina – Terezka a Matýsek

Nová plná verze dětského anglického modulu FajnCvičebny.

Navazuje na původní `ter-mat.html` v repozitáři `fdc-plugin`, který zůstává beze změny.

## Směr vývoje

- jasná výuková cesta: **Nauč mě to → Procvičování → Mluvím → Příběh → Svět**
- určeno hlavně pro mladší školní věk
- aktivní poslech a mluvení, ne jen klikání
- kontrola výslovnosti přes stávající FajnDoučko pronunciation API
- skutečný progres a herní svět Matýska a Terezky
- oddělení „prošel jsem“ od „umím“
- krátké, srozumitelné aktivity bez trestání dítěte za chybu

## Stav

Základ nové architektury. Původní modul se nemaže ani nepřepisuje.
